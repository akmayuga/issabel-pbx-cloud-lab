Issabel PBX Cloud Lab

A portfolio-ready VoIP lab project with Infrastructure as Code, Asterisk/PJSIP extensions, IVR, voicemail, call recording, monitoring, backups, security hardening, and deployment documentation.

Deployment Guide Architecture Network Security SIP Clients Call Tests Free Publish Strategy

Lab Features

PBX Core

Issabel 5 with Asterisk, PJSIP extensions 1001 and 1002, voicemail, internal calling, transfer support, and CDR.

Call Flows

IVR 700, ring group 600, time condition 800, and call recording with MixMonitor.

Automation

Terraform for infrastructure, Ansible for configuration, and shell scripts for health checks, backup, restore, DNS, TLS, and VPN.

Operations

Fail2Ban, firewalld, Prometheus, Grafana, Node Exporter, Asterisk service metrics, and daily backup timers.

Live PBX demo

A live Issabel PBX needs a real VM with UDP SIP/RTP ports. Use Oracle if approved, Azure for Students if eligible, or Google Cloud free tier with a billing account.

This project is for learning and lab demonstrations. Do not expose real SIP credentials or production call traffic.
